# Photorealistic backgrounds

These 26 landscapes were created with the built-in image_gen tool for this project. They are AI-generated images, not photographs documenting specific real locations. The exact generation prompts are recorded in `prompts.json`.

Portrait JPEGs are stored at 1080 × 1920 and cropped centrally for feed posts. The renderer embeds local image bytes directly in the SVG, so generation requires no image hosting or external network access. A subtle image overlay and a separate dark scripture panel keep the quotation readable.

To replace a scene, provide a JPEG with the same name and verify both the 1080 × 1350 post and 1080 × 1920 story/reel crop. No scripture should be baked into the background image.
